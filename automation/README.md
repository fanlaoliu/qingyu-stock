# 青嶼研究室｜24/7 自主開發執行器（準備階段）

此資料夾定義**常駐開發服務的安全邊界**，不是已啟動的 AI 代理。

## 需要的基礎設施
- 一台可長時間運行的主機／容器平台（VPS 或常駐服務）
- GitHub App 或最小權限 Token（只授權本 repository）
- AI API 金鑰及每月費用上限
- 隔離的工作目錄與測試環境
- 受保護的 main 分支、PR 審查及部署狀態回報

## 執行循環
1. 讀取 main、CI 狀態、待辦清單。
2. 從 automation/tasks.json 選一項未完成低風險任務。
3. 在隔離分支修改程式、加入測試。
4. 執行 quality-gate；失敗則停止、留下紀錄。
5. 成功後建立 PR；通過檢查與既定核准規則後才合併。
6. 驗證 Cloudflare 部署，記錄結果，再繼續下一項。
7. 設定預算、速率限制、錯誤次數熔斷與緊急停止。

## 目前狀態
僅有 GitHub CI 與 ChatGPT 定期任務；**尚未有常駐主機、API 金鑰或可執行的 AI coding agent**。不能宣稱已經 24 小時運作。

## 安全限制
不得將 API 金鑰提交到 GitHub；不得自行更改權限、金流、刪除資料、對外服務條款或跳過測試。禁止將未驗證的金融資料當成官方資料發布。
