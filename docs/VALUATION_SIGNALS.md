# 個股估值訊號（Draft，2026-11-07）

沿用雙專家引擎，不新增資料供應商、模型費用或交易功能。本次只更新Draft PR #15，不部署或合併。

## 顯示位置

股票篩選列表新增「估值訊號」欄；一般個股研究卡、雙專家研究標題、精選候選卡及情境估值結果均顯示訊號。文字與顏色一起表達，不只靠顏色。雙專家頁揭露研究日、行情日、安全邊際、基準合理價區間及原因，原有來源證據仍可展開。匯出研究報告包含`valuationSignal`供重現。

## 明確判斷

首先須有7日內的已確認授權聲明行情（此聲明不等於獨立授權稽核）、報價與K線版本一致、至少兩種適用估值、可用且新鮮的TTM與原有完整三情境。方法差異超過設定值（預設30%）、未完成產業專屬模型或其他估值問題時標為待複核。缺資料不補0、不從PE倒推EPS。

|訊號|初始研究規則|
|---|---|
|估值偏高，留意風險|現價／基準當期合理價中位數−1 ≥20%，且現價高於該基準各估值方法區間上緣|
|估值偏低，可研究買入|安全邊際`1−現價／基準當期合理價中位數`達設定（預設20%），且現價不高於該基準各法區間下緣；原有完整選股資格、財務、評分、流動性與風控門檻全部通過|
|估值偏低，等待條件確認|價格達上述偏低條件，但完整研究資格尚未全數通過；揭露未通過或缺漏原因，不發買入訊號|
|估值合理區間／持續觀察|未達上述偏高或偏低條件；此文字不是企業價值已獲證實|
|估值待複核／無法判定|方法差異過大、資料不足、報價過期、未完成產業模型、來源待核對等|
|合成測試，不提供買入訊號|輸入明示synthetic，永不發實際買入訊號|

以上門檻是透明初始設定，尚未經歷史有效性驗證。「可研究買入」仍須人工覆核，不是實際買入指令、上漲機率或損失保證，不新增自動下單。

列表的價格與行情日期必須與研究報告完全對齊（價格容許0.001元浮點誤差），不同市場也不共用訊號。否則顯示「報價版本不一致，待重算」，避免將舊價研究訊號貼到新報價。設定／計算失敗時清除舊訊號。估值頁單獨修改EPS成長／倍數只做情境試算，不沿用舊的完整候選資格發買入訊號；按「重新計算」才重做全模型。

既有真實資料未齊，本次不會因此讓1964檔報價自動變成可推薦公司。來源、資料缺口、模型假設、估值方法與風險計算沿用[主驗收紀錄](DUAL_ENGINE_V1.md)。
