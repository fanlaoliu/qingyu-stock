# 歷史歸檔與固定參數滾動驗證

## 本批已實作

- `scripts/archive_history.py`接在每日官方行情抓取之後，將完整公開快照按SHA256歸檔到`data/history/`，索引記錄交易日期、真正觀測時間及檔名。同內容不改首次觀測時間；修訂保留舊版本。未知或未歸檔的過去資料不回填。
- 歸檔只有公開官方行情，不含帳本、筆記或匯入財報。歷史檔不在靜態網站資產白名單，不隨網站打包。
- 回測頁加入固定參數滾動驗證。設定訓練／測試筆數，測試區段不重疊；每段以相同資金獨立起算，最後強制平倉，再將各段報酬複利串接。訓練期為測試期的1至9倍，均線期數不超過訓練期；不自動挑最佳參數。
- 顯示各段起迄日期、報酬、回撤、交易次數及整體串接回撤。尾端不足完整測試區段不使用，明列筆數。結果與原始輸入可從既有匯出按鈕保存。

## 驗證與限制

Node 62項及Python 59項測試通過，23個公開資產建置成功。新增測試涵蓋首次觀測時間、重複歸檔、修訂保存、錯誤資料拒絕、精確切分、不重疊測試區段、複利及修改未來資料不影響先前區段。

尚未合併或正式部署，排程歸檔尚未正式啟用，沒有宣稱已擁有多年歷史資料。歸檔記錄的是抓取時可見版本，不能證明原始公告時間，也不等於還原權息行情；不可直接標記成total-return匯入回測。完整全市場回測還需要公司行動、下市資料與交易日曆。歸檔會隨每日快照成長，尚未建立長期外部儲存及保留政策。

本批滾動驗證採固定策略、沒有參數最佳化；不是投資有效性證明。自動財報、同步與推播、AI帳戶實際啟用、真實iPhone驗收仍待完成。
