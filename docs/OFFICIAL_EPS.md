# 官方EPS摘要接線

本批將官方上市／上櫃各產業EPS統計資料接入每日資料更新管線，新增獨立的`data/financial-summary.json`與進階研究頁的官方EPS摘要。與手動TTM財報獨立，不能代入合理價、完整評分或歷史回測。

2026-11-01實際讀取：上市46筆、上櫃38筆，合計84筆。這是當時接口回傳的部分公司，不能代表完整市場財報覆蓋率。缺少公司不補0；負EPS與真實0保留。

資料包含報表期末、官方年度與季別、EPS原始值、出表日期、擷取時間及來源URL。`publishedAt`保持null：出表日期不是公司原始公告日。官方季度／累計口徑尚未逐份財報核對，不標記為TTM，不將季度乘4或用股價除PE倒推EPS。

單一市場抓取或欄位驗證失敗時保留該市場舊資料與擷取時間，顯示來源錯誤；全部來源失敗不覆寫檔案。前端重新讀取失敗時保留前次資料與日期，無資料時明確顯示錯誤。
