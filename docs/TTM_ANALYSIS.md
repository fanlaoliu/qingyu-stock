# TTM及ROE分析

三大財報工作台新增「計算TTM與ROE」及證據JSON匯出。僅支援曆年制、1月1日至標準季末的累計／年度報表；輸入為有來源、公告日、明確期間且以TWD記錄的合併三表。

公式：當期累計＋上一年度全年−上一年度同期累計。完整年度直接使用年度數值。不加總重疊累計報表、不將單季乘4。每一欄位有缺值即保留null。報表先以查詢日排除未公告版本；相同期間使用截至該日最新修訂。

TTM ROE採合併TTM淨利除期初期末總權益平均；兩端權益須為正且可用，否則null。這是總權益口徑，非母公司普通股ROE。完整年度計算ROE也需要前一年年末權益，該來源會一併列入證據。

跨期現金需核對本年期初與去年年末、去年全年與去年同期的現金起點。資料齊全時再次檢查TTM期初、期末及三類現金流加匯率調節；不連續時拒絕推導，缺值則明列未核對。TTM資本支出不可為負。輸出包含TTM收入、淨利、營業現金流、自由現金流、平均權益、ROE、每份來源與公告日。

此功能不推算EPS，也不自動加入合理價、完整評分或回測。官方原始摘要缺少公告日、已核對的金額單位與現金流，因此不能直接餵入本引擎；自動完整財報、金融業、完整歷史、同步推播、AI實際綁定仍未完成。匯入者仍需核對公司重編、合併範圍及會計口徑。

來源方法核對：
- https://www.xero.com/us/glossary/ttm/ （會計軟體供應商的TTM公式說明）
- https://mopsfin.twse.com.tw/ （證交所財務比較公式：權益報酬率採稅後純益／平均權益）
