# 青嶼研究室：產品架構與分階段交付計畫

狀態：規劃提案（非功能已完成證明）｜2026-11-01

## 不變原則
- 保留現有靜態 HTML/JS、Python TWSE/TPEx 更新、GitHub Actions、Cloudflare Workers；避免不必要的框架重寫。
- 所有功能走 feature branch → CI / secret scan → PR → 預覽驗收 → 人工核准合併 → **另行人工核准正式部署**。PR 合併不應直接觸發正式部署；部署自動化現況需由 Cloudflare 設定另行查核。
- 僅使用可追溯的官方或合約允許來源；資料附來源、交易日期、擷取時間、單位、缺值及錯誤狀態。缺漏不填造，不以 0 取代 null。
- 投資模型不宣稱保證報酬。評分與合理價皆附方法、樣本、假設及風險。

## 分階段開發順序及驗收條件

### P0 資料品質與核心選股（PR #6 進行中；其餘另開 PR）
1. 驗證交易日期、估值日期、營收月份及法人日期一致性；依市場報告缺漏率、重複代號、無效值、異常值與來源錯誤。
2. 驗證熱力圖排序、缺值置底、產業排除與鍵盤操作。
3. 驗證多策略 AND 交集、取消單條件、無結果、儲存/載入及舊版設定相容性。
4. 評分拆成可追溯子分數：基本面50%、籌碼25%、人氣15%、技術10%。**只有具備合法、日期有效的來源才啟用相應子分數**；缺少人氣或技術面時顯示「未能完整評分」，不可將其餘項目放大到100分，也不可混稱現有 30/30/15/25 研究優先度。
驗收：Python/Node 回歸測試、來源缺漏測試、桌面及 iPhone 瀏覽器測試、CI 與 Secret scan 通過。

### P1 進階研究
法人 5/20 日累計與連買連賣、營收/EPS/ROE/現金流/負債、歷史估值區間與情境合理價。
驗收：資料期間與單位核對；每個估值情境附假設，禁止缺值推算。

### P2 投資組合
自選、成本、損益、資產與產業集中度、風險警示；先本機資料，跨裝置同步須另提隱私與身分驗證方案。
驗收：股數、拆股、配息、交易費、匯入匯出、敏感資料不公開。

### P3 AI 研究助理
附來源連結與日期的財報摘要、事件變化、研究理由、反方論點；LLM 金鑰只在伺服器秘密儲存，不進前端/儲存庫。
驗收：引用可追溯、資料不足拒絕編造、成本與速率限制。

### P4 回測與績效
歷史資料版本、避免前視偏誤、倖存者偏誤、交易成本與滑價、樣本外/滾動驗證。
驗收：可重現、明列資料缺口與限制，不用回測結果保證未來。

### P5 iPhone 與部署
PWA 操作、iOS 專案、離線警示、無障礙、效能、安全標頭、Cloudflare 預覽與人工部署核准。
驗收：iPhone Safari 與主畫面模式測試、預覽 URL 驗證、正式部署需另行核准。

## 待核對風險
- Cloudflare 是否在 main 合併後自動部署正式環境（必須確認並建立可靠的阻擋機制）。
- 當前資料快照日期與欄位涵蓋率、官方來源 API 穩定性。
- CI 覆蓋的瀏覽器與裝置、歷史籌碼缺日情形。
- 人氣與技術指標的合法資料來源、更新頻率及回測基準。
- 公開 GitHub 儲存庫的機密掃描、資產白名單及依賴風險。
