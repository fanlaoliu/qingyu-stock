# Code Review
Reference: https://github.com/garrytan/gstack (review workflow; upstream tool not bundled).
Review data schema compatibility, missing PE/PB handling, XSS/HTML injection, fetch errors, date/time correctness, responsive UI and test coverage. Report severity, affected file, reproduction, and suggested fix. Never merge automatically.
